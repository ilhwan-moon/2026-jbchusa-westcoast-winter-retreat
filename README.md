# 2026 미주서부 동계수련회 안내 (모바일)

휴대폰으로 보는 4개 언어(한국어 · English · Español · 中文) 수련회 안내 페이지입니다. GitHub Pages로 무료 운영합니다.

- 주소: https://ilhwan-moon.github.io/2026-jbchusa-westcoast-winter-retreat/
- 언어별 링크: `/ko/` `/en/` `/es/` `/zh/` (주소에 `?lang=`이 항상 남아 카톡 → 다른 브라우저 열기, 홈 화면 추가 때도 언어가 유지됩니다)
- 검색엔진에는 나오지 않습니다(noindex). 링크를 받은 사람만 볼 수 있습니다.

## 화면
1. **일정**: 맨 위에 「상담 신청하기」·「홍보 영상 보기」 버튼. 날짜별 시간표. 수련회 기간에는 LA 시간 기준 「지금 / 다음 순서」가 맨 위에 나옵니다.
2. **말씀·장소**: 전체 말씀, 말씀 장소 ①~⑦, 언어별 성경 강연회, 언어권별 교제, 상담 신청(QR), 주제 말씀
3. **생활 안내**: 숙소, 지켜 주세요, 자녀 안내, 준비물 체크리스트, 3일째 청소 구역
4. **연락처**: 응급·의료, 진행 문의, 부서 책임자(누르면 전화), 지도

## 내용 고치기
`data.js` 한 파일만 고치면 됩니다. 각 문장은 `L('한국어', 'English', 'Español', '中文')` 순서입니다.
시간은 24시간제로 씁니다(오후 6:50 → `'18:50'`).

## 확인용
주소 끝에 `&now=2026-11-28T10:15`를 붙이면 그 시각 기준 「지금」 화면을 미리 볼 수 있습니다.

## 홍보 영상
`data.js`의 `video.youtube`에 유튜브 영상 ID(예: `https://youtu.be/41c0XBJCZZc` → `41c0XBJCZZc`)를 넣습니다.

## 줄바꿈 규칙
문장 안의 ` · `로 나뉜 부분과 `(괄호)` 부분은 한 덩어리로 묶여, 줄이 넘치면 덩어리째 다음 줄로 내려갑니다. 새 내용도 이 규칙으로 쓰면 됩니다. 예: `2026년 11월 27일(금) ~ 29일(일) · 2박 3일`

## 공지 띠
`data.js`의 `notices`에 넣으면 모든 화면 맨 위에 나옵니다. `from`~`until`(LA 시간) 동안만 보이고, 사용자가 ✕로 닫을 수 있습니다.
앱을 켜 둔 사람도 3분 안에 새 공지가 보입니다. 빨강은 `level: 'urgent'`, 파랑은 `level: 'info'`입니다.

## 그 밖의 기능
- 오른쪽 위 국기 버튼 → 설정 화면: 언어(한국 · 미국 · 멕시코 · 중국 국기), 글씨 크기 3단계, 화면(밝게·어둡게·자동). 고른 값은 휴대폰에 기억됩니다.
- 첫 화면 「전체 말씀 · 대강당」: 말씀 1~4 날짜·시간, 다음 말씀 표시, 시작 30분 전부터 「⏰ ○분 후 시작」(`app.js`의 `SOON`)
- 일정: 날짜별 보기 / 전체 일정표(3일 한 표) 전환, 27·28·29일에는 그날 자동 선택
- 은은한 눈꽃 효과(`snow.js`). 휴대폰의 「동작 줄이기」 설정이면 꺼집니다.

## 사용법 영상 (홈 화면 바로가기 안내)
- 4개 언어: `video/howto_ko.mp4`, `howto_en.mp4`, `howto_es.mp4`, `howto_zh.mp4` (세로 1080×1920, 약 95초)
- 아이폰 사파리 · 아이폰 크롬 · 안드로이드 · 카톡에서 홈 화면에 추가하는 방법을 단계별로 보여 줍니다.
- 다시 만들기: 사이트를 `python3 -m http.server 8765`로 띄운 뒤
  `node video/capture.js` (앱 화면 캡처) → `python3 video/bgm.py 95.3` (배경음악: Amazing Grace, 직접 합성) → `node video/record.js ko` (언어별)
- 장면과 자막은 `video/howto.html`에서 고칩니다.
