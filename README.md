# 2026 미주서부 동계수련회 안내 (모바일)

휴대폰으로 보는 4개 언어(한국어 · English · Español · 中文) 수련회 안내 페이지입니다. GitHub Pages로 무료 운영합니다.

- 주소: https://ilhwan-moon.github.io/2026-jbchusa-westcoast-winter-retreat/
- 언어별 링크: `/ko/` `/en/` `/es/` `/zh/` (주소에 `?lang=`이 항상 남아 카톡 → 다른 브라우저 열기, 홈 화면 추가 때도 언어가 유지됩니다)
- 검색엔진에는 나오지 않습니다(noindex). 링크를 받은 사람만 볼 수 있습니다.

## 화면
1. **일정**: 날짜별 시간표. 수련회 기간에는 LA 시간 기준 「지금 / 다음 순서」(장소 포함)와 오늘 시간표가 맨 위에 나오고, 포스터는 맨 아래로 내려갑니다. 수련회 전후에는 포스터가 맨 위입니다.
2. **말씀·장소**: 전체 말씀, 말씀 장소 ①~⑦, 언어별 성경 강연회, 언어권별 교제, 상담 신청(QR), 주제 말씀
3. **생활 안내**: 숙소, 지켜 주세요, 자녀 안내, 준비물 체크리스트, 3일째 청소 구역
4. **연락처**: 응급·의료, 진행 문의, 부서 책임자(누르면 전화), 지도

### 쓰기 편하게 해 둔 것
- 내려 읽을 때는 맨 위에 언어·글씨 크기 줄만 남아 내용이 더 많이 보입니다. 날짜 탭은 그 바로 아래에 붙어 따라옵니다.
- 「말씀·장소」「생활 안내」 맨 위의 바로가기 버튼을 누르면 그 항목으로 바로 내려갑니다.
- 아래 메뉴에서 지금 보고 있는 메뉴를 다시 누르면 맨 위로 올라갑니다.
- 바로가기 버튼 이름은 `app.js` 의 `jump` 에서 고칩니다(4개 언어).

## 내용 고치기
`data.js` 한 파일만 고치면 됩니다. 각 문장은 `L('한국어', 'English', 'Español', '中文')` 순서입니다.
시간은 24시간제로 씁니다(오후 6:50 → `'18:50'`).

## 확인용
주소 끝에 `&now=2026-11-28T10:15`를 붙이면 그 시각 기준 「지금」 화면을 미리 볼 수 있습니다.
